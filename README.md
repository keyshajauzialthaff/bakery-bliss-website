# bakery-bliss-website
A bakery e-commerce website built with PHP, MySQL, HTML, CSS, and JavaScript.

# Bakery Bliss – Online Bakery Website
Bakery Bliss is a web-based bakery ordering system designed to provide customers with a simple and convenient online shopping experience.

## Features

### Customer Features
- User Registration and Login
- Browse Bakery Products
- Shopping Cart
- Checkout and Place Orders
- View Order History
- View Order Details

### Admin Features
- Admin Dashboard
- View Order Statistics
- Manage Customer Orders
- Update Order Status
- View Order Details

## Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap 
- XAMPP
- Visual Studio Code

## Database
The website uses MySQL to store:
- User Information
- Product Information
- Customer Orders
- Order Details

## How to Run the Project
1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Clone or download this repository.
4. Place the project folder inside `htdocs`.
5. Create a database named `bakery_bliss` in phpMyAdmin.
6. Import the database SQL file.
7. Configure your database connection in `includes/db.php`.
8. Open your browser and visit:

   `http://localhost/bakery-bliss/`

## Project Purpose
This project was developed as a web development project to implement basic e-commerce functionality for an online bakery business.
